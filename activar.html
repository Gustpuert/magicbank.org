🧠 Cómo usar correctamente tu tutor

Cuando entres al tutor, estarás dentro de un chat. Ese chat es donde ocurre todo tu aprendizaje.


Es muy importante mantener el orden para que el tutor pueda enseñarte bien.

Regla principal:

En cada chat debes trabajar un solo tema.


Si mezclas temas diferentes, el tutor pierde claridad y tu aprendizaje se vuelve confuso.



📂 Cómo organizar tus chats

En la parte superior izquierda verás un menú (☰).


Al hacer clic, se abre una barra lateral donde están todos tus chats.


Desde allí puedes:

    

  • Crear un chat nuevo para otro tema
    • 

  • Entrar a chats anteriores
    • 

  • Organizar tu aprendizaje
    • 

Muy importante:

Cada chat debe tener un nombre claro.


Por ejemplo:

    

  • Inglés Módulo 1
    • 

  • Contabilidad básica
    • 

  • Marketing digital
    • 


Para renombrarlo:


Haz clic sobre el nombre del chat → selecciona "Renombrar" → escribe el nombre.


Siempre que quieras continuar un tema, debes entrar al mismo chat.



🎤 Uso correcto de voz y escritura

Dentro del tutor puedes escribir o hablar.


Pero es muy importante no mezclar ambos en el mismo chat.


El micrófono (🎤) sirve solo para dictar texto.


El botón de conversación (el que está al extremo derecho) es el que permite hablar directamente con el tutor.

Uso correcto:
    

  • Un chat solo para voz → VOZ (Inglés)
    • 

  • Otro chat solo para escribir → Inglés Módulo 1
    • 


Si mezclas voz y escritura, el sistema puede perder orden y afectar tu aprendizaje.
